## 📖 Sobre o Projeto

Este repositório não é apenas um site de hamburgueria. É um **diário de bordo** que documenta minha evolução como desenvolvedor.

Comecei com um arquivo HTML simples e, através de 9 módulos incrementais, transformei o projeto em uma aplicação **TypeScript** robusta, com arquitetura orientada a objetos, testes automatizados e uma interface visual de nível profissional.

O objetivo deste repositório é demonstrar minha capacidade de **evoluir código, refatorar, aplicar boas práticas e aprender novas tecnologias de forma contínua**.

## 🚀 Como Executar a Versão Final

A versão mais avançada é a **`v2-js9-css9`**. Para rodá-la:

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/vh-burguer.git
```

2. Acesse a pasta final:

```bash
cd vh-burguer/v2-js9-css9
```

3. Instale as dependências:

```bash
npm install
```

4. Compile o TypeScript:

```bash
npm run build
```

5. Rode os testes:

```bash
npm test
```

6. Abra o `index.html` no navegador via **Live Server**.
