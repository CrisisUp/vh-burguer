## 📋 Sobre o Projeto

Site multipáginas da **VH Burger**, uma hamburgueria artesanal fictícia.
Desenvolvido como parte da **Atividade 2 – Linguagem de Marcação (SA 1 – Desafio 2)**,
aplicando os principais elementos do HTML5 com estrutura semântica.

## 🎯 Objetivo

Aplicar os principais elementos da linguagem **HTML** para estruturação de conteúdo,
utilizando títulos, parágrafos, formatação, listas, links e **tags semânticas HTML5**.

## 📁 Estrutura do Projeto

```text
v3/
│
├── index.html          # Página inicial (Home)
├── cardapio.html       # Cardápio completo
├── sobre.html          # Sobre a hamburgueria
├── contato.html        # Contato e localização
└── README.md           # Documentação
```

## 📄 Páginas do Site

| Página | Arquivo | Descrição |
| ------ | ------- | --------- |
| 🏠 Home | `index.html` | Apresentação, destaques e como pedir |
| 🍔 Cardápio | `cardapio.html` | Lista completa de produtos e preços |
| 👤 Sobre | `sobre.html` | História, missão, valores e equipe |
| 📞 Contato | `contato.html` | Endereço, telefone, e-mail e horários |

## ✅ Checklist da Atividade

### Estrutura Básica

- [x] `<!DOCTYPE html>`
- [x] `<html lang="pt-br">`
- [x] `<head>` com `<meta charset>` e `<meta viewport>`
- [x] `<title>` específico em cada página
- [x] `<body>` em todas as páginas

### Semântica HTML5

- [x] `<header>` — cabeçalho padrão em todas as páginas
- [x] `<nav>` — menu de navegação entre as 4 páginas
- [x] `<main>` — conteúdo principal de cada página
- [x] `<section>` — blocos temáticos do conteúdo
- [x] `<footer>` — rodapé com direitos autorais

### Elementos de Conteúdo

- [x] Título principal (`<h1>`) — "VH Burger"
- [x] Subtítulos (`<h2>`, `<h3>`) — seções
- [x] Parágrafos (`<p>`) — textos explicativos
- [x] Formatação: `<strong>`, `<em>`, `<b>`, `<i>`, `<small>`
- [x] Lista não ordenada (`<ul>`) — itens do cardápio
- [x] Lista ordenada (`<ol>`) — passos e valores
- [x] Links (`<a>`) — navegação interna
- [x] Quebra de linha (`<br>`) — endereços e descrições
- [x] Linha horizontal (`<hr>`) — separação de seções

## 🧩 Estrutura Semântica Aplicada

| Seção | Descrição | Tags Utilizadas |
| ----- | --------- | --------------- |
| Cabeçalho | Título principal e navegação | `<header>`, `<h1>`, `<nav>`, `<a>` |
| Conteúdo | Blocos principais | `<main>`, `<section>` |
| Rodapé | Direitos autorais | `<footer>`, `<small>` |

## 🚀 Como Executar o Projeto

1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/vh-burger.git
```

1. Acesse a pasta v3

```bash
cd vh-burger/v3
```

1. Abra o `index.html` no navegador:
   - Clique duas vezes, ou
   - Use **Live Server** no VS Code
