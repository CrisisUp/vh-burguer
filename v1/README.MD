## 📋 Sobre o Projeto

Este repositório contém o desenvolvimento da página inicial do site da **VH Burger**, uma hamburgueria artesanal fictícia. O projeto foi desenvolvido como parte da **Atividade 2 – Linguagem de Marcação (SA 1 – Desafio 2)**, com o objetivo de aplicar os principais elementos da linguagem HTML para estruturação de conteúdo, transformando o wireframe criado no Figma em uma página HTML funcional.

## 🎯 Objetivo da Atividade

Aplicar os principais elementos da linguagem **HTML** para estruturação de conteúdo, utilizando:

- Títulos
- Parágrafos
- Formatação de texto
- Listas
- Links

## ✅ Checklist da Atividade

### 1. Título Principal (`<h1>`)

- [x] Utilizado para o nome da hamburgueria **"VH Burger"**.

### 2. Parágrafo Introdutório (`<p>`)

- [x] Texto de boas-vindas apresentando a hamburgueria.

### 3. Formatação de Texto

- [x] `<strong>` — destaque com importância semântica.
- [x] `<em>` — ênfase no texto.
- [x] `<b>` — destaque visual em negrito.
- [x] `<i>` — destaque visual em itálico.
- [x] `<small>` — texto pequeno (aplicado no rodapé).

### 4. Lista Não Ordenada (`<ul>`)

- [x] Utilizada para listar os itens do cardápio:
  - [x] Hambúrgueres
  - [x] Acompanhamentos

### 5. Lista Ordenada (`<ol>`)

- [x] Utilizada para mostrar o passo a passo de **"Como Fazer seu Pedido"**.

### 6. Links (`<a>`)

- [x] Links de navegação no topo (Home, Cardápio, Como Pedir, Contato).
- [x] Link no final para voltar à página inicial.

### 7. Quebra de Linha e Linha Horizontal (`<br>` e `<hr>`)

- [x] `<br>` usado para formatar o endereço e horário.
- [x] `<hr>` usado para separar seções (cardápio, pedido, contato).

### 8. Estrutura Básica do HTML

- [x] `<!DOCTYPE html>`
- [x] `<html>`
- [x] `<head>`
- [x] `<title>`
- [x] `<body>`

### 9. Hierarquia de Títulos

- [x] `<h2>` e `<h3>` utilizados para subtítulos e seções.

### 10. Comentários e Indentação

- [x] Código indentado corretamente.
- [x] Comentários explicando cada seção do código.

## 🧩 Estrutura da Página

| Seção | Descrição | Tags Utilizadas |
| ----- | --------- | --------------- |
| Cabeçalho | Título principal e navegação | `<h1>`, `<nav>`, `<a>`, `<hr>` |
| Apresentação | Boas-vindas à hamburgueria | `<h2>`, `<p>`, `<strong>`, `<em>`, `<br>` |
| Cardápio | Itens do cardápio | `<h2>`, `<h3>`, `<ul>`, `<li>`, `<b>`, `<i>` |
| Como Pedir | Passo a passo do pedido | `<h2>`, `<ol>`, `<li>` |
| Contato | Informações de contato | `<h2>`, `<p>`, `<br>`, `<a>` |
| Rodapé | Direitos autorais | `<footer>`, `<small>` |

## 🚀 Como Executar o Projeto

### 1. **Clone o repositório:**

```bash
git clone https://github.com/seu-usuario/vh-burger.git
```

### 2. **Acesse a pasta do projeto:**

```bash
cd vh-burger
```

- Clique duas vezes no arquivo, ou
- Clique com o botão direito → *Abrir com* → Navegador de sua preferência.
