## 📋 Sobre o Projeto

Primeira evolução visual e interativa do site multipáginas da VH Burger.

Esta pasta adiciona **CSS moderno** e **primeiras interações em JavaScript** à versão base (v2).

## 🎯 O Que Foi Adicionado

### CSS (Visual)

- Variáveis CSS (`:root`) para paleta centralizada
- Fonte Inter (Google Fonts)
- Fundo escuro + destaque amarelo
- Menu estilizado horizontal
- Transições e hover suaves
- Layout centralizado (max-width: 900px)
- Caixas de destaque (`.destaque-box`)

### JavaScript (Interatividade)

- **Saudação dinâmica** baseada na hora do dia
- **Data atual** por extenso (sábado, 18 de outubro de 2026)
- **Menu ativo** (destaca a página atual)
- **Relógio ao vivo** no rodapé
- **Botão "voltar ao topo"** que aparece ao rolar
